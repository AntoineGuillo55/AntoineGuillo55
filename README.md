## Hello 👋

I'm **Antoine Guillo**, a freelance web developer based in Rennes, France. Under the **[À Code Ouvert](https://acodeouvert.fr)** brand, I help small and mid-sized businesses design, build and grow their web projects.

My approach holds in a single idea: **scope it right before you code it**. A successful web project is decided upfront — in the conversations, the understanding of the actual need, and the technical choices made before the first line of code.
